// PROCESS

How I Approach Testing

A repeatable six-step flow — from requirements to release — that keeps coverage high and surprises low.

01

Understand Requirements

Review specifications and acceptance criteria, ask questions early, and clarify edge cases with stakeholders before writing a single test.

02

Create Test Scenarios

Map requirements to test scenarios, prioritizing business risk and the areas most likely to break.

03

Design Test Cases

Write clear, reusable test cases with expected results, keeping RTM traceability back to each requirement.

04

Execute Tests

Run functional, smoke, sanity, integration, API, and cross-browser/device tests — manually and methodically.

05

Report & Track Defects

Log defects with repro steps, severity, and evidence in JIRA, then track them through the full defect life cycle.

06

Regression & Release Validation

Re-verify fixes, run regression packs, and support release validation and production issue analysis.
